# M0 Setup

Date: 2026-11-15. Machine: macOS (Darwin 24.6, x86_64), 12 cores, 32 GB RAM, 694 GB free disk.

## What was built

- Conda environment `bowpilot` from `environment.yml` (Python 3.11.18, rasterio 1.4.4, geopandas 1.2.0, R survey 4.5). Package installed with `pip install -e .`.
- Package layout as specified in `docs/milestones/M0_setup.md`. Every module has a docstring stating its responsibility.
- `config.py`: loads the six YAML files, resolves the active extent, applies `dev_overrides`, and validates budgets, purity thresholds, crosswalk targets, `draws_from` links and the Monte Carlo profile.
- `grid.py`: the `Grid` class (CRS, transform, shape, windows, cell index and row/col conversion, JSON round trip).
- `logging_utils.py`: logs to `logs/<step>_<timestamp>.log` and the console.
- `cli.py`: typer app with `data`, `population`, `validate-estimators`, `validate-sampling`, `montecarlo` (with `--resume`), `report`, `status`. Each accepts `--extent dev|full`.
- Tests: `tests/test_config.py` extended with loader and rejection tests. `tests/test_truth_isolation.py` now has a regex test and an AST test.
