## Dev smoke run (50 replicates; a smoke test, not evidence)

Date: 2026-11-15. Profile: dev (R = 50, bootstrap subset 10, B = 50). Base seed 20261115. HYPOTHESES.md is not frozen yet. It will be frozen at the start of full M5; this section has no verdicts.

### What was built

- `simulate/montecarlo.py`: one SeedSequence child per (drawing arm, budget) in a fixed order, and one grandchild per replicate. Each replicate's integer seed is stored in every row and fully determines the replicate. Each draw is evaluated by every arm that reuses it: A0 to A0w, A1 to A1 at tau 0.75, 0.9, 1.0 and B1 at tau 0, 0.75, 0.9, 1.0, D to E. Arm D also writes per-state domain estimates and model-assisted area. Replicates run in parallel with joblib processes. One Parquet file per (arm, budget, tau). `--resume` skips files whose row count is complete. The real CVPR test split is evaluated once with A0 and A0w.
- `simulate/metrics.py`: estimates_summary (R_def, undefined rate, mean, truth, bias, relative bias, MCSE, RMSE, empirical SD, mean SE, SE ratio, coverage, MCSE of coverage, mean CI width). Truth scope `all`, plus the matching `restricted_tau` scope for A1 and B1. Also efficiency, domain and area summaries. The truth is read from `truth.parquet` only after estimation; the truth module is never imported.
- `simulate/ranking.py`: probability of the true best model, Kendall tau-b, exact-ranking share (H0), pairwise decision classes (correct-significant, not significant, Type S) and the sign-flip rate. For OA, design arms use the design CI and naive arms McNemar on pooled cells. F uses sqrt(se_k^2 + se_l^2), since its samples are independent.
